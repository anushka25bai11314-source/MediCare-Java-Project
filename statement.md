# MediCare – Hospital/Clinic Management System

## 1. Problem Statement

Managing patients, doctors, appointments, prescriptions, and billing manually can be time-consuming and can lead to errors, duplicate records, scheduling conflicts, and difficulty in maintaining organized information.

MediCare is a Java-based hospital/clinic management system designed to provide a simple and organized way to manage essential healthcare-related operations through a single application. The system allows users to maintain patient and doctor records, schedule appointments, manage prescriptions, generate bills, and provide appointment reminders.

The project demonstrates how Java programming concepts such as Object-Oriented Programming, collections, exception handling, validation, synchronization, and multithreading can be applied to solve a practical problem.

---

## 2. Scope of the Project

The scope of MediCare includes the management of basic hospital and clinic operations through a terminal-based Java application.

The system covers:

- Patient registration and record management
- Doctor registration and record management
- Appointment scheduling and management
- Prevention of doctor double-booking
- Prescription management
- Medicine details within prescriptions
- Bill generation and payment status management
- Appointment reminders using multithreading
- Input validation and error handling
- Searching and viewing stored records

The project is intended as an academic Java application and uses in-memory data storage. It does not include online appointment booking, real-time hospital networking, or integration with external healthcare databases.

---

## 3. Target Users

The primary target users of MediCare are:

- **Clinic Receptionists** – to register patients and manage appointments.
- **Doctors** – to view patient appointments and manage prescriptions.
- **Clinic/Hospital Staff** – to manage billing and patient-related records.
- **Students and Developers** – to understand the implementation of Java concepts in a real-world application.

---

## 4. High-Level Features

### Patient Management
- Add new patients
- View patient records
- Search patient information
- Update and manage patient details

### Doctor Management
- Add doctor records
- View available doctors
- Search doctor information
- Manage doctor details

### Appointment Management
- Book appointments
- View appointments
- Search appointments
- Cancel appointments
- Reschedule appointments
- Prevent double-booking of doctors

### Prescription Management
- Create prescriptions
- Add multiple medicines to a prescription
- View prescription details
- Associate prescriptions with patients and doctors

### Billing Management
- Generate patient bills
- View bill details
- Track payment status
- Manage billing information

### Reminder System
- Provide appointment reminders
- Use Java multithreading for reminder processing

### Validation and Error Handling
- Validate user inputs
- Handle invalid data and exceptions
- Prevent invalid appointment operations
- Display meaningful error messages

---

## 5. Project Objective

The main objective of MediCare is to develop a modular Java-based management system that simplifies basic clinic operations while demonstrating important Java programming concepts including:

- Object-Oriented Programming
- Classes and Objects
- Inheritance and Abstraction
- Encapsulation
- Collections
- Exception Handling
- Regular Expressions
- Multithreading
- Synchronization
- Modular programming
